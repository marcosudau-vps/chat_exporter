## 2. Nicht im Umfang

- andere Betriebssysteme als Windows; Installation pro Rechner;
- automatische Programm-Updates (ein neuer Installer aktualisiert);
- automatische Übernahme von Daten älterer Testprogramme (`~/.chat_exporter`;
  der Weg von Hand steht in [GETTING_STARTED.md](GETTING_STARTED.md));
- automatische Anmeldung über Google, Microsoft oder Apple, mit Passkeys oder mit
  Code per E-Mail; Umgehen von Sicherheitsprüfungen (grundsätzlich nie);
- Ideen aus dem Bericht zur ChatGPT_API-Auswertung
  (BERICHT_CHATGPT_API_AUSWERTUNG.md), etwa
  das Sichern von Kontodaten oder Token-Injektion (Planung);
- alles unter [BEKANNTE_EINSCHRAENKUNGEN.md](BEKANNTE_EINSCHRAENKUNGEN.md).

## 3. Abnahmekriterien

Ein Kandidat ist abnahmefähig, wenn **alle** Punkte belegt sind
(RELEASE.md, Abschnitt 2):

1. Testsuite grün.
2. Komplett-Test des Installers auf frischem Windows ohne Fehler
   ([packaging/sandbox](../packaging/sandbox/README.md)).
3. Testablauf Teile A, B und C bestanden
   ([TESTABLAUF_ENTWICKLUNGSMODUS.md](TESTABLAUF_ENTWICKLUNGSMODUS.md)): echte
   Anmeldung, Erstabruf, Folgelauf, lokal gelöschte Chats, unbeaufsichtigter
   geplanter Lauf mit automatischer Anmeldung, Profilkopie mit Schließen und
   Wiederöffnen des echten Browsers.
4. In der Doku ist nichts mehr als offen markiert. Was nicht geht, steht in
   [BEKANNTE_EINSCHRAENKUNGEN.md](BEKANNTE_EINSCHRAENKUNGEN.md).
5. Keine Secrets im Code, in Beispielen oder im Installer; keine
   Entwicklungsreste im Release-Paket.
6. Menschliche Abnahme (`_governance/PROMOTION_RULES.md`).
