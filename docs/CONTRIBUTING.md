# Beiträge

Fehlerberichte mit Version, Windows-Version, erwartetem und beobachtetem Verhalten
sowie einem reproduzierbaren Beispiel mit erfundenen Daten. Keine Kontoexporte,
Browserprofile oder Zugangsdaten hochladen.

Änderungen über Pull Requests. Provider verwalten ihre Quelldaten; Raw Session
Updater koordiniert die Quellen; Exporte lesen Rohdaten und verändern sie nicht.
Codeänderungen durch passende Tests und die gesamte aktive Suite prüfen.
Produktdokumentation nach erfolgreicher Prüfung aktualisieren.

Einrichtung: [README](../README.md), [Tests](TESTING.md), [Build](BUILD.md).
Abhängigkeitsänderungen müssen `requirements-ci.lock` aktualisieren.
Release-Entwürfe werden erst nach menschlicher Abnahme veröffentlicht.
